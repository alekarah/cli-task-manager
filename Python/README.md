# Менеджер Задач (Python)

Персональный менеджер задач с CLI интерфейсом на языке Python.

## Возможности

- ✅ Создание задач с названием и описанием
- ✏️ Редактирование существующих задач
- 📊 Отслеживание статуса задач (todo, in_progress, done)
- 🎯 Управление приоритетами задач (low, medium, high)
- ⏰ Установка дедлайнов с автоматической индикацией просроченных задач
- 🏷️ Теги для категоризации задач
- 📋 Просмотр всех задач
- 🔍 Фильтрация задач по статусу или тегам
- 🔎 Поиск задач по тексту в названии или описании
- 🔄 Сортировка задач (по ID, дате создания, дате обновления, статусу, приоритету)
- 📤 Экспорт задач в CSV и Markdown
- 🗑️ Удаление задач
- 💾 Автоматическое сохранение в JSON файл

## Требования

- Python 3.7 или выше

## Запуск

```bash
python main.py
```

Или (для Linux/Mac):
```bash
chmod +x main.py
./main.py
```

## Использование

После запуска программы доступны следующие команды:

1. **list** (или 1) - показать все задачи
2. **add** (или 2) - добавить новую задачу
3. **update** (или 3) - обновить задачу (название, описание, статус, приоритет, дедлайн, теги)
4. **delete** (или 4) - удалить задачу
5. **filter** (или 5) - фильтровать задачи по статусу или тегам
6. **search** (или 6) - поиск задач по тексту
7. **sort** (или 7) - сортировать задачи
8. **export** (или 8) - экспортировать задачи в CSV или Markdown
9. **exit** (или 9) - выход из программы

## Структура проекта

- `main.py` - основной файл с CLI интерфейсом
- `task.py` - класс задачи и методы работы с ней
- `storage.py` - управление хранением данных
- `test_task.py` - юнит-тесты для класса `Task`
- `test_storage.py` - юнит-тесты для класса `Storage`
- `tasks.json` - файл с данными (создается автоматически)

## Тесты

Проект покрыт юнит-тестами на стандартном модуле `unittest`. Всего **58 тестов**.

### Запуск всех тестов:
```bash
python -m unittest test_task test_storage -v
```

### Запуск отдельно:
```bash
python -m unittest test_task -v      # 26 тестов для Task
python -m unittest test_storage -v   # 32 теста для Storage
```

### Что покрыто:

**`test_task.py`** — класс `Task`:
- Создание задачи и значения по умолчанию
- Обновление статуса (валидные/невалидные значения)
- Обновление полей (название, описание)
- Обновление приоритета (валидные/невалидные значения)
- Установка и очистка дедлайна
- Теги: добавление, удаление, дедупликация, нормализация регистра, фильтрация пустых
- Сериализация `to_dict()` / десериализация `from_dict()` (включая формат `Z`-суффикса)

**`test_storage.py`** — класс `Storage`:
- CRUD: добавление, получение, удаление, список задач
- Фильтрация по статусу и тегам
- Полнотекстовый поиск (без учёта регистра, по названию и описанию)
- Получение всех уникальных тегов
- Сортировка (по ID, приоритету, статусу, дате обновления)
- Персистентность: сохранение и загрузка из JSON
- Экспорт в CSV и Markdown

## Примеры использования

### Добавление задачи:
```
Введите команду: add
Название задачи: Изучить Python
Описание задачи: Пройти туториал по Python

✓ Задача #1 успешно создана!
```

### Обновление задачи:
```
Введите команду: update
Введите ID задачи: 1

Что вы хотите обновить?
1. Название и описание
2. Статус
3. Приоритет
4. Дедлайн
5. Всё сразу

Выберите опцию: 4
Текущий дедлайн: не установлен
Введите новый дедлайн в формате ДД.ММ.ГГГГ ЧЧ:ММ
Или просто ДД.ММ.ГГГГ (время будет 23:59)
Или оставьте пустым для удаления дедлайна
Дедлайн: 15.01.2026

✓ Задача успешно обновлена!
```

### Фильтрация по статусу:
```
Введите команду: filter
Выберите статус для фильтрации: 1

=== Задачи со статусом 'todo' ===
[список задач со статусом todo]
```

### Поиск задач:
```
Введите команду: search
Введите текст для поиска: Python

=== Результаты поиска для 'Python' ===
[список задач, содержащих слово Python]
```

### Сортировка задач:
```
Введите команду: sort

Доступные варианты сортировки:
1. id - по ID
2. created - по дате создания (сначала старые)
3. updated - по дате обновления (сначала новые)
4. status - по статусу
5. priority - по приоритету (сначала высокий)

Выберите вариант сортировки: 5

=== Задачи, отсортированные по приоритету ===
[список задач: сначала high 🔴, затем medium 🟡, затем low 🟢]
```
