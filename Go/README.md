# Менеджер Задач (Go)

Персональный менеджер задач с CLI интерфейсом на языке Go.

## Возможности

- ✅ Создание задач с названием и описанием
- ✏️ Редактирование существующих задач
- 📊 Отслеживание статуса задач (todo, in_progress, done)
- 🎯 Управление приоритетами задач (low, medium, high)
- ⏰ Установка дедлайнов с автоматической индикацией просроченных задач
- 🏷️ Теги для категоризации задач
- 📋 Просмотр всех задач
- 🔍 Фильтрация задач по статусу или тегам
- 🔎 Поиск задач по тексту в названии или описании
- 🔄 Сортировка задач (по ID, дате создания, дате обновления, статусу, приоритету)
- 📤 Экспорт задач в CSV и Markdown
- 🗑️ Удаление задач
- 💾 Автоматическое сохранение в JSON файл

## Запуск

### Запуск без сборки:
```bash
go run .
```

**Важно:** Используйте `go run .` (с точкой), а не `go run main.go`, чтобы скомпилировать все файлы пакета.

### Сборка и запуск:
```bash
go build -o task-manager.exe
./task-manager.exe
```

## Использование

После запуска программы доступны следующие команды:

1. **list** (или 1) - показать все задачи
2. **add** (или 2) - добавить новую задачу
3. **update** (или 3) - обновить задачу (название, описание, статус, приоритет, дедлайн, теги)
4. **delete** (или 4) - удалить задачу
5. **filter** (или 5) - фильтровать задачи по статусу или тегам
6. **search** (или 6) - поиск задач по тексту
7. **sort** (или 7) - сортировать задачи
8. **export** (или 8) - экспортировать задачи в CSV или Markdown
9. **exit** (или 9) - выход из программы

## Структура проекта

- `main.go` - основной файл с CLI интерфейсом
- `task.go` - структура задачи и методы работы с ней
- `storage.go` - управление хранением данных
- `task_test.go` - юнит-тесты для `Task`
- `storage_test.go` - юнит-тесты для `Storage`
- `tasks.json` - файл с данными (создается автоматически)

## Тесты

Проект покрыт юнит-тестами на стандартном пакете `testing`. Всего **50 тестов**.

### Запуск всех тестов:
```bash
go test ./... -v
```

### Запуск с отображением только провалов:
```bash
go test ./...
```

### Что покрыто:

**`task_test.go`** — структура `Task`:
- Создание задачи и значения по умолчанию
- Обновление статуса, приоритета, полей задачи
- Установка и очистка дедлайна, обновление `UpdatedAt`
- Теги: добавление, удаление (включая нормализацию регистра), дедупликация, фильтрация пустых
- Обновление временной метки `UpdatedAt` при всех изменениях (статус, дедлайн, теги)

**`storage_test.go`** — структура `Storage`:
- CRUD: добавление, получение, удаление, список задач (включая пустое хранилище)
- Фильтрация по статусу и тегам (несколько совпадений, нормализация регистра)
- Полнотекстовый поиск (без учёта регистра, по названию и описанию)
- Получение всех уникальных тегов с сортировкой
- Сортировка (по ID, приоритету, статусу, дате создания, дате обновления) без мутации оригинала
- Персистентность через JSON marshal/unmarshal
- Экспорт в CSV (BOM-заголовок, содержимое строк, теги с `#`) и Markdown (все статусы, пустое хранилище)
- Экранирование кавычек `escapeCSV`

## Примеры использования

### Добавление задачи:
```
Введите команду: add
Название задачи: Изучить Go
Описание задачи: Пройти туториал по Go

✓ Задача #1 успешно создана!
```

### Обновление задачи:
```
Введите команду: update
Введите ID задачи: 1

Что вы хотите обновить?
1. Название и описание
2. Статус
3. Приоритет
4. Дедлайн
5. Всё сразу

Выберите опцию: 4
Текущий дедлайн: не установлен
Введите новый дедлайн в формате ДД.ММ.ГГГГ ЧЧ:ММ
Или просто ДД.ММ.ГГГГ (время будет 23:59)
Или оставьте пустым для удаления дедлайна
Дедлайн: 15.01.2026

✓ Задача успешно обновлена!
```

### Фильтрация по статусу:
```
Введите команду: filter
Выберите статус для фильтрации: 1

=== Задачи со статусом 'todo' ===
[список задач со статусом todo]
```

### Поиск задач:
```
Введите команду: search
Введите текст для поиска: Go

=== Результаты поиска для 'Go' ===
[список задач, содержащих слово Go]
```

### Сортировка задач:
```
Введите команду: sort

Доступные варианты сортировки:
1. id - по ID
2. created - по дате создания (сначала старые)
3. updated - по дате обновления (сначала новые)
4. status - по статусу
5. priority - по приоритету (сначала высокий)

Выберите вариант сортировки: 5

=== Задачи, отсортированные по приоритету ===
[список задач: сначала high 🔴, затем medium 🟡, затем low 🟢]
```
