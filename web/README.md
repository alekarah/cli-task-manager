# Менеджер Задач (Web — Terminal UI)

Браузерная версия менеджера задач с интерфейсом в стиле терминала.  
Реализована на **React + TypeScript**, данные хранятся в **localStorage** — бэкенд не нужен.

## Возможности

- Терминальный интерфейс с псевдографикой и цветовой схемой Tokyo Night
- История команд — навигация стрелками ↑↓
- Tab-автодополнение команд
- Все операции с задачами: создание, просмотр, редактирование, удаление
- Фильтрация по статусу и тегам
- Полнотекстовый поиск
- Сортировка по разным критериям
- Данные сохраняются между перезагрузками страницы

## Запуск

```bash
npm install
npm run dev
```

Открыть в браузере по адресу, который Vite выведет в терминале после запуска

### Сборка для продакшена:
```bash
npm run build
```

## Команды терминала

| Команда | Описание | Пример |
|---|---|---|
| `help` | Список всех команд | `help` |
| `list` | Все задачи | `list` |
| `add "название" "описание"` | Создать задачу | `add "Изучить React" "Пройти туториал"` |
| `delete <id>` | Удалить задачу | `delete 3` |
| `update <id> <поле> <значение>` | Обновить поле | `update 1 status done` |
| `filter status <статус>` | Фильтр по статусу | `filter status todo` |
| `filter tag <тег>` | Фильтр по тегу | `filter tag backend` |
| `search <текст>` | Поиск | `search авторизация` |
| `sort <критерий>` | Сортировка | `sort priority` |
| `tags` | Все теги | `tags` |
| `clear` | Очистить экран | `clear` |

### Поля для update

| Поле | Допустимые значения |
|---|---|
| `status` | `todo`, `in_progress`, `done` |
| `priority` | `low`, `medium`, `high` |
| `deadline` | `ДД.ММ.ГГГГ` или `none` |
| `tags` | теги через запятую: `api,backend,devops` |
| `title` | новое название |
| `desc` | новое описание |

### Критерии сортировки

`id` · `created` · `updated` · `status` · `priority`

## Структура проекта

```
web/
├── src/
│   ├── components/
│   │   ├── Terminal.tsx          # главный компонент, буфер строк, обработка команд
│   │   ├── TerminalLine.tsx      # рендер одной строки с нужным цветом
│   │   ├── CommandInput.tsx      # строка ввода, история, Tab-автодополнение
│   │   └── Terminal.module.css   # стили тёмной темы
│   ├── core/
│   │   ├── commands.ts           # парсинг и выполнение команд
│   │   └── storage.ts            # CRUD-операции поверх localStorage
│   ├── types.ts                  # общие типы TypeScript
│   ├── App.tsx
│   └── main.tsx
├── index.html
├── package.json
└── vite.config.ts
```

## Технологии

- **React 19** — UI
- **TypeScript** — типизация
- **Vite** — сборка и dev-сервер
- **CSS Modules** — изолированные стили
- **localStorage** — хранение без бэкенда
